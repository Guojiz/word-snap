A bilingual vocabulary matching app with immediate feedback, custom word lists, adaptive review, and PWA installation.

The maintained app lives on the official site. This repository is the public project page, license, and contribution notes for that live practice surface.

## Official website

**https://guojiz.github.io/word-snap/**

Use the site to:

- start a matching round without installing anything;
- add or edit a personal word list;
- get immediate right/wrong feedback;
- review misses with an adaptive queue;
- install it as a PWA on desktop or phone when you want it on the home screen.

## What it is for

Word Snap is a short practice loop, not a course platform.

- **Bilingual matching** — pair a word with its meaning, then keep going.
- **Immediate feedback** — see the miss as soon as it happens.
- **Your list** — practice the vocabulary you actually need.
- **Adaptive review** — come back to the items that did not stick.
- **PWA** — optional install; the website remains the source of truth.

## Start

1. Open **[the official website](https://guojiz.github.io/word-snap/)**.
2. Start a round.
3. If the browser offers it, install the PWA for one-tap practice.

Contributions should make that first practice action faster, clearer, and easier on both desktop and mobile. See [CONTRIBUTING.md](CONTRIBUTING.md). Maintainers: [MAINTAINING.md](MAINTAINING.md).

## 它解决什么

Word Snap 是短练习闭环，不是课程平台。

- **双语配对** — 把词和释义对上，然后继续。
- **即时反馈** — 错了立刻看见。
- **自己的词表** — 练真正需要的词。
- **自适应复习** — 回到还没记住的条目。
- **PWA** — 可选用；官网始终是正式入口。

## 开始

1. 打开 **[官网](https://guojiz.github.io/word-snap/)**。
2. 开始一轮练习。
3. 浏览器提供安装时，可把 PWA 放到主屏幕。

贡献应让第一次练习更快、更清楚，并同时照顾桌面和手机。见 [CONTRIBUTING.md](CONTRIBUTING.md)。维护清单：[MAINTAINING.md](MAINTAINING.md)。
