# Contributing

Thank you for considering a contribution.

This project is a lightweight vocabulary matching practice page. Contributions should make practice faster, clearer, and easier to use on both desktop and mobile.

## Good contributions

Useful contributions include:

- bug fixes for matching behavior;
- mobile layout improvements;
- accessibility improvements;
- clearer practice flow;
- small vocabulary or data-format improvements;
- performance improvements;
- documentation fixes.

## Do not contribute

Please do not include:

- copyrighted word lists that cannot be redistributed;
- private classroom records;
- user tracking or analytics without discussion;
- large unrelated UI redesigns in the same pull request as logic changes;
- secrets, tokens, cookies, or account information.

## Before opening a pull request

1. Keep the change focused.
2. Describe the practice flow you tested.
3. Test on a desktop viewport and a mobile viewport when the change affects UI.
4. Include before and after notes for visible behavior changes.
5. Open an issue first for major gameplay, scoring, or data-format changes.

## AI-assisted contributions

AI-generated drafts are welcome, but please review them before submission and say when a change was drafted with AI assistance.
